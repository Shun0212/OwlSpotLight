OwlSpotlight Help / ヘルプ

Getting started

Open a project, choose a search mode on first setup, and describe the code you want to find. To change modes later, open VS Code Settings and search for owlspotlight.searchBackend, or run OwlSpotlight: Open Search Backend Settings.

backend_server(python) starts a local Python search server. Install uv first, then run Setup Python Environment. Setup is designed to keep manual configuration to a minimum: the GPU auto-detect option checks your NVIDIA GPU and driver and selects a compatible PyTorch/CUDA build from the supported versions. If no compatible GPU build is found, it uses the CPU build. Apple Silicon can use MPS acceleration where supported.

If the Python backend still will not run, try node_onnx, the simple version that runs on the CPU inside VS Code without a Python server. Setup and startup failures automatically switch to this mode; you can also select it in extension settings. Its model downloads on the first semantic search. BM25 and keyword search do not require the model.

Check View → Output → OwlSpotlight for setup errors and progress. The Python server runs in the background and selects another local port if the default is busy.

Commands

Open the Command Palette (Cmd+Shift+P / Ctrl+Shift+P) and type OwlSpotlight. Commands use the selected search mode.

  • Code Search / Find Similar to Selection: search from the sidebar or selected code. Both support ONNX mode.
  • Clear Cache: clears the search cache. In ONNX mode, stops the current operation and removes embeddings, keeping downloaded models. Embeddings are rebuilt as needed on the next search.
  • Cancel Indexing / Embedding: stops the active operation in either mode.
  • Start Server / Stop Server: starts or stops the Python backend. In ONNX mode, Start Server updates the status without starting a server; Stop Server stops the current search operation.
  • Setup Python Environment: sets up the Python backend. In ONNX mode, displays a message that Python setup is unnecessary.
  • Remove Virtual Environment: removes the Python environment after confirmation. It does not remove ONNX models or embeddings.
  • Generate Agent Setup: creates MCP configuration for the selected mode. ONNX mode supports owlspotlight.search_code and owlspotlight.read_code; annotations, feedback, and Agent Activity require the Python backend.

使い始めるには

プロジェクトを開き、初回セットアップで実行方式を選んで、探したいコードの内容を入力してください。変更するには、VS Codeの設定で owlspotlight.searchBackend を検索するか、OwlSpotlight: Open Search Backend Settings を実行します。

backend_server(python) はローカルのPython検索サーバーを起動します。先に uv をインストールし、Setup Python Environment を実行してください。なるべく手軽に構築できるよう、GPU自動判定ではNVIDIA GPUとドライバーを確認し、対応するPyTorch/CUDAのバージョンを選びます。対応するGPU用ビルドが見つからない場合はCPU版を使用します。Apple Siliconでは、対応環境でMPSによる高速化を利用できます。

それでもPythonバックエンドを実行できない場合は、簡易版の node_onnx も試してみてください。Pythonサーバーを構築せず、VS Code内でCPU実行できます。環境構築・起動に失敗した場合は自動的に切り替わるほか、拡張機能の設定からも選択できます。モデルは初回の意味検索時にダウンロードします。BM25・Keyword検索にはモデルは不要です。

進捗やエラーは 表示 → 出力 → OwlSpotlight で確認できます。Pythonサーバーはバックグラウンドで動作し、既定のポートが使用中なら別の空きローカルポートを選びます。

コマンド

コマンドパレット（Cmd+Shift+P / Ctrl+Shift+P）で OwlSpotlight と入力してください。選択中のモードに合わせて動作します。

  • Code Search / Find Similar to Selection：サイドバーや選択したコードから検索します。ONNXモードにも対応しています。
  • Clear Cache：検索キャッシュを削除します。ONNXモードでは実行中の処理を停止し、ダウンロード済みモデルを残して埋め込みを削除します。次回検索時に必要な埋め込みを再生成します。
  • Cancel Indexing / Embedding：どちらのモードでも実行中の処理を停止します。
  • Start Server / Stop Server：Pythonバックエンドを起動・停止します。ONNXモードでは、Start Serverはサーバーを起動せず状態表示を更新し、Stop Serverは実行中の検索処理を停止します。
  • Setup Python Environment：Python環境を構築します。ONNXモードではセットアップ不要と案内します。
  • Remove Virtual Environment：確認後にPython環境を削除します。ONNXのモデルや埋め込みは削除しません。
  • Generate Agent Setup：選択中のモードに合わせたMCP設定を作成します。ONNXモードでは owlspotlight.search_code と owlspotlight.read_code に対応します。結果注釈・フィードバック・Agent ActivityはPython版の機能です。

Gemini translation and search / 翻訳・検索改善

Open Settings → Gemini Search → API key & data sharing in the sidebar to save your Gemini API key and review what is shared. Enable JP → EN for query translation or Agentic search for search refinement. These optional features work in both modes and send queries and inspected code to Google.

サイドバーの Settings → Gemini Search → API key & data sharing で、送信内容を確認してGemini APIキーを保存できます。クエリ翻訳は JP → EN、検索改善は Agentic search を有効にしてください。どちらのモードでも利用でき、クエリや参照したコードをGoogleへ送信します。
